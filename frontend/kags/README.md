# bobcat_default

## Project setup
```
yarn install
```

### Compiles and hot-reloads for development with mocked api calls
```
yarn run serve
```

### Compiles and hot-reloads for development with dev api calls 
require filled VUE_APP_API_TOKEN in env.devapi
```
yarn run serve-api
```

### Gets Bearer Token for dev api calls
require filled OKTA_LOGIN and OKTA_PASSWORD in env.devapi
```
yarn run get-token
```

### Compiles and minifies for production
```
yarn run build
```

yarn run test

yarn run lint
